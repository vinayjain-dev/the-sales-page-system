# 30 headline formulas

How to use this file:

1. Write the buyer's problem in their own words first. Copy the phrase from a review, a comment, or a sales call.
2. Pick two or three formulas that fit the offer. Fill them in, using real facts only.
3. Check each option against the five tests below. Keep the one that passes all five.

**Five tests for every headline:**

1. **Specific.** It names an outcome, a person, or a situation. "More clients" fails. "Book 3 more dental consults a week" passes if true.
2. **Short.** Under about 12 words for a headline, under about 8 for a subject line.
3. **In their words.** A stranger would say it this way.
4. **True.** Every number, claim, and outcome is one the seller can show.
5. **Commands or promises.** It ends the scroll with a reason to keep reading, not a description of the product.

Fill-ins are in `{{CAPS}}`. Examples use fictional businesses. Numbers in examples are shown as `[N]` so no real-looking
result is implied.

---

## A. Promise and outcome

**1. Outcome without the pain**
- Template: `{{OUTCOME}} without {{PAIN THEY WANT TO AVOID}}.`
- Example: `More booked appointments without cold calling.`
- Use when: the buyer is tired of a specific chore.

**2. The one thing**
- Template: `All you have to do is {{ONE STEP}}.`
- Example: `All you have to do is answer the first form.`
- Use when: the process looks big and the first step is small.

**3. Finally**
- Template: `Finally, {{OUTCOME}} that doesn't {{PAIN}}.`
- Example: `Finally, a sales page you can build in one afternoon.`
- Use when: the buyer has tried and failed before.

**4. Timeframe, only if real**
- Template: `{{OUTCOME}} in {{REAL TIME}}, not {{USUAL SLOW TIME}}.`
- Example: `A first draft page in one afternoon, not one month.`
- Use when: the time is measured and the seller can show it.

**5. Before and after, only if real**
- Template: `From {{START STATE}} to {{END STATE}}.`
- Example: `From a blank page to a page you're proud to send.`
- Use when: the change is concrete and visible.

**6. The result they want, named**
- Template: `{{RESULT}}, built for {{SPECIFIC AUDIENCE}}.`
- Example: `Steady quote requests, built for independent plumbers.`
- Use when: the audience is narrow and the result is clear.

## B. Tension and truth

**7. The uncomfortable truth**
- Template: `Your {{THING THEY OWN}} is {{UNCOMFORTABLE TRUTH}}.`
- Example: `Your homepage is quietly costing you calls.`
- Use when: the reader already suspects the truth and has not admitted it.

**8. Still doing this?**
- Template: `Still {{PAINFUL HABIT}} every {{TIME UNIT}}?`
- Example: `Still rewriting the same follow-up email every Monday?`
- Use when: the reader repeats a habit without enjoying it.

**9. It's not your fault**
- Template: `It's not your {{TRAIT}}. It's the {{METHOD}}.`
- Example: `It's not your writing. It's the template you copied.`
- Use when: the reader has blamed themselves for a method's failure.

**10. Skeptical? You should be.**
- Template: `Skeptical? You should be. {{HONEST SETUP LINE}}.`
- Example: `Skeptical? You should be. Here's exactly what you get.`
- Use when: the offer is new or the claim is bold. Follow it with proof.

**11. Would it surprise you**
- Template: `Would it surprise you that I {{REAL RESULT}}?`
- Example: `Would it surprise you that I built my first page in [N] days?` (only if the seller did)
- Use when: the seller has a real result the reader will doubt.

**12. The myth**
- Template: `"{{COMMON BELIEF}}" is only half true.`
- Example: `"More traffic fixes everything" is only half true.`
- Use when: the reader holds a belief that is partly wrong.

## C. Who it is for

**13. This is for, not for**
- Template: `This is for {{SPECIFIC PERSON}}. Not for {{WRONG PERSON}}.`
- Example: `This is for owners who sell services. Not for hobby sellers.`
- Use when: you want to filter out the wrong buyers early, which saves ad money.

**14. Identity**
- Template: `For {{IDENTITY}} who are done with {{PAIN}}.`
- Example: `For coaches who are done with unpaid discovery calls.`
- Use when: the reader identifies with a role.

**15. Insider**
- Template: `What {{INSIDERS}} know about {{TOPIC}} that {{OUTSIDERS}} don't.`
- Example: `What good plumbers know about quote follow-up that most don't.`
- Use when: the seller has real insider knowledge. Keep it specific.

**16. Permission**
- Template: `Yes, you can {{OUTCOME}}, even if {{LIMITING BELIEF}}.`
- Example: `Yes, you can build a sales page, even if you've never coded.`
- Use when: the reader doubts their own ability.

## D. Mechanism and process

**17. The named system**
- Template: `The {{N}}-step {{SYSTEM NAME}} that {{RESULT}}.`
- Example: `The five-step page system that puts the offer above the fold.`
- Use when: the process is simple and countable.

**18. How to, so you can**
- Template: `How to {{THING}}, so you can {{BENEFIT}}.`
- Example: `How to write your own offer, so you can stop discounting it.`
- Use when: the product is a how-to. This is the most used formula in long-form pages.

**19. Stop and start**
- Template: `Stop {{OLD ACTION}}. Start {{NEW ACTION}}.`
- Example: `Stop designing for yourself. Start designing for the buyer.`
- Use when: the old habit is clear and the switch is small.

**20. The contrast with the expensive option**
- Template: `What {{EXPENSIVE OPTION}} charges. What you can do this {{TIME UNIT}}.`
- Example: `What an agency charges for one page. What you can do this afternoon.`
- Use when: the offer replaces a costly service. The price claim must be real.

**21. The hidden benefit**
- Template: `The best part isn't {{SURFACE BENEFIT}}. It's {{HIDDEN BENEFIT}}.`
- Example: `The best part isn't the page. It's knowing exactly what to say on it.`
- Use when: the product's real gain is less obvious than its features.

## E. Command and urgency (honest)

**22. The short command**
- Template: `Build your {{ASSET}} {{TIME}}.`
- Example: `Build your first sales page this afternoon.`
- Use when: the next step is one action with a short duration.

**23. Get it now, plainly**
- Template: `Get {{PRODUCT}} for ${{PRICE}}, {{DELIVERY}}.`
- Example: `Get the full kit for $[PRICE], delivered instantly.`
- Use when: the buyer is ready. Good for the price block and the sticky bar.

**24. Real deadline only**
- Template: `{{PRODUCT}} closes {{REAL DATE}}. {{WHAT THEY GET BY THEN}}.`
- Example: `The cohort closes on [DATE], and you start the same week.`
- Use when: a real date exists that the seller will honour. Delete it otherwise.

**25. Cost of waiting, real**
- Template: `Every {{TIME UNIT}} you wait is another {{REAL COST}}.`
- Example: `Every week without a page is another week of ads sending people nowhere.`
- Use when: the cost is real and the seller can state it plainly.

## F. Proof and credibility (labelled)

**26. Real number with a source**
- Template: `{{REAL NUMBER}} {{PEOPLE}} {{DID THING}} with {{METHOD}}.`
- Example: `[N] owners built their first page with this method.` (only with a real count)
- Use when: the number is real, current, and sourced. Label it.

**27. The seller's own result**
- Template: `I {{RESULT}} using {{METHOD}}. My own result, not typical.`
- Example: `I built my first paying page in [N] days. My own result, not typical.`
- Use when: the seller's result is real. Always include the label.

**28. Credibility from a named person**
- Template: `{{NAME}}, {{ROLE}}, on {{OUTCOME}}.`
- Example: `[NAME], [ROLE], on [THEIR RESULT IN THEIR WORDS].` (only with permission and a real quote)
- Use when: a real testimonial is strong and named.

## G. Reframes and fresh angles

**29. The smarter way**
- Template: `The smarter way to {{GOAL}} is {{SURPRISING APPROACH}}.`
- Example: `The smarter way to get a quote request is a page that answers the first question.`
- Use when: the reader assumes the usual approach is the only one.

**30. The new method reveals**
- Template: `New {{METHOD}} reveals a {{COUNTERINTUITIVE}} way to {{RESULT}} without {{PAIN}}.`
- Example: `New sales page method reveals a simpler way to get calls without a bigger budget.`
- Use when: the method is genuinely new or counterintuitive. The "new" must be true.

## Subject-line shortcuts (email)

Keep subject lines under about eight words. Patterns that work well:

- `{{Name}}, quick question about {{PRODUCT}}`
- `Did something go wrong?`
- `{{Specific result}}`
- `This is for one kind of person`
- `Your {{product}} is ready`
- `In or out?`

Never use a subject that pretends the reader has a message from a person they do not know, or that claims a payment
or account problem that does not exist.
